# usaeventpartner.com

US event production and local support for international brands, agencies and marketing teams.

This repository follows the same production pattern as `merch.mt` and `corp-merch.eu`: static SEO-first build, Cloudflare Worker lead handling, preview/noindex protection, analytics hooks and a release checklist.

## Current stage

Design-direction and production scaffold.

Three review directions are being prepared:

1. **Corporate US** — strict, modern US B2B event-production look.
2. **American Heritage** — slightly conservative, established, operations-led visual language.
3. **Network Edition** — structurally closest to merch.mt / corp-merch.eu, but with a distinct US palette.

The selected direction will become the production root. Alternative design routes will remain noindex review pages until final cleanup.
